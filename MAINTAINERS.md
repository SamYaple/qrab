Maintainers review and merge pull requests, triage issues, cut releases and
handle security and Code of Conduct reports. They are the code owners in
[.github/CODEOWNERS](.github/CODEOWNERS). [GOVERNANCE.md](GOVERNANCE.md)
describes the role and how to become a maintainer.

## Contacting the maintainers

- Questions, bugs and feature requests: open an
  [issue](https://github.com/qrab-dev/qrab/issues).
- Changes: open a pull request; see [CONTRIBUTING.md](CONTRIBUTING.md).
- Security issues: do not open a public issue. Follow
  [SECURITY.md](SECURITY.md).
- Code of Conduct reports: see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

You can also mention a maintainer by GitHub handle on an issue or pull
request.

## Automation

Coding agents that work on qrab act through the `qrab-dev-agent[bot]` GitHub
App. The App is not a maintainer and cannot approve its own pull requests; a
human maintainer reviews everything it opens.
