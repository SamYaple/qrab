# Code of Conduct

qrab follows the [CNCF Code of
Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).
It applies to everyone who takes part in the project: in the repositories,
issues, pull requests and discussions, and at events where people represent
qrab.

## Reporting

Report a violation to the qrab maintainers at
[conduct@qrab.dev](mailto:conduct@qrab.dev). Reports are handled in
confidence. If a maintainer is involved, or you would rather not contact the
maintainers, report it to the CNCF instead, as described in the [CNCF Code of
Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

The maintainers acknowledge each report, review it and decide on a response
that is proportionate to what happened. A maintainer who is the subject of a
report takes no part in handling it.
