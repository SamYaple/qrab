# VM operator

The namespaced Rust operator owns only VM Pods, their ConfigMaps, NIC Pods and their relay CiliumNetworkPolicies, and the
CHAP Secrets of storage-service provisioned disks. PVCs and
console entrypoints stay explicit Kubernetes resources; never garbage collect
TPM/firmware identity storage. Keep one replica with Recreate rollout strategy.

The CRD is generated by `cargo run -p qrab-operator -- crd` into
`contrib/kubernetes/operator/crd.json`. Edit the Rust API and regenerate.
No guest NIC, arbitrary Pod template, anonymous BMC or Kubernetes API token in a
VM pod: guest NICs are separate NIC Pods (docs/networking.md). Keep image digests pinned, validate ownership before patch/delete, and
set immutable CR UID as manager state_id. See docs/operator.md and docs/spire-vm.md.

Run `contrib/check-runtime.sh` and the documented live CR lifecycle checks.
