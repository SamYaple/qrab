# qapi-macros

Proc-macro crate providing the `#[qapi]` attribute. Applied to types generated by `qapi-codegen` to produce version-aware serialization.

## What it generates

- Manual `Serialize` and `Deserialize` impls using wire-format field names
- Runtime version gating — fields are serialized only when the connected QEMU version is in range
- `QapiCommand` and `QapiEvent` trait impls for command and event types

## Attributes

| Attribute | Level | Purpose |
|-----------|-------|---------|
| `added = "X.Y.Z"` | type, field, variant | First version where this exists |
| `deprecated = "X.Y.Z"` | type, field, variant | Version where this was deprecated |
| `removed = "X.Y.Z"` | type, field, variant | Version where this was removed |
| `name = "..."` | type, field, variant | Wire-format name (JSON key) |
| `condition = "..."` | field, variant | Compile-time condition (`#[cfg]`) |
| `command` | type | Generates `QapiCommand` impl |
| `event` | type | Generates `QapiEvent` impl |
| `returns = "Type"` | type | Return type for commands |
| `flatten` | field | Inline nested struct fields into the parent |
| `discriminator` | field | Union discriminator field |
