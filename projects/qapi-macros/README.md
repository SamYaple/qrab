# qapi-macros

A proc-macro crate that provides the `#[qapi(...)]` attribute macro. This macro is used by the autogenerated `qapi` crate to produce QEMU QAPI-compatible Rust types with version-aware serialization.

## The `#[qapi]` attribute

Applies to structs and enums. Supports the following parameters:

| Level | Attribute | Effect |
|---|---|---|
| Type | `since = "X.Y"` | Minimum QEMU version for the entire type |
| Field/Variant | `name = "..."` | Wire-format name, emitted as `#[serde(rename = "...")]` |
| Field/Variant | `since = "X.Y"` | Minimum QEMU version for this field/variant |
| Field/Variant | `condition = "..."` | Conditional compilation flag (currently stubbed) |

## What it generates

**For enums:** Injects `#[serde(rename = "...")]` on variants that have a `name` attribute, preserving the mapping between Rust-idiomatic names and QAPI wire-format names.

**For structs:** In addition to serde renames, generates a custom `impl serde::Serialize` that:

- Gates the entire struct on `runtime_version() >= since` (if a type-level `since` is set)
- Gates individual fields on their own `since` version
- Handles `Option<T>` fields by only serializing when `Some`

The generated serialization code calls a `runtime_version()` function that must be in scope (provided by the `qapi` crate).
