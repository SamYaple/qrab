# qapi

Autogenerated Rust type definitions for the [QEMU QAPI](https://www.qemu.org/docs/master/devel/qapi-code-gen.html) schema. **Do not modify this crate directly** -- it is regenerated by `qapi-spec-parser`.

## Regenerating

```sh
cargo run -p qapi-spec-parser -- vendor/qemu > projects/qapi/src/lib.rs
```

## What's included

The crate provides Rust enums and structs corresponding to QEMU's QAPI type system:

- **Enums** for QAPI enum and alternate types (e.g., `IoOperationType`, `OnOffAuto`, `PcieLinkSpeed`)
- **Structs** for QAPI struct, command, and event types (e.g., `HumanReadableText`)
- **Version-aware serialization** via `#[qapi(since = "...")]` attributes, gated on the `runtime_version()` function defined in this crate
- **Wire-format name mapping** between Rust-idiomatic names and QAPI's kebab-case/numeric identifiers

The current generated code targets QEMU 9.1.0.
